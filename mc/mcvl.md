# mc-version-list

Minecraft 版本列表拉取器。

- 链接: <https://github.com/sb-child/mc-version-list>
- 编程语言: ![go](https://img.shields.io/badge/-Go-black?logo=Go)

项目状态：现在没人用了，项目停滞。

---

## 简介

做这个项目是因为之前 [LiteZero](https://github.com/LiteZero) 做的 Minecraft BDS 服务器面板需要有地方拉取版本信息，但是不想在易语言里写复杂的解析逻辑...

然后这个项目就只是服务于他的软件。程序通过 GitHub Action 每隔一段时间就拉取版本信息然后存到 [这个 Gist](https://gist.github.com/sb-child/b5a133b71e0a66b26360dff030906bc6)。
