# mytm

刚好能用的任务管理器，可以用在你的下一个项目里。

- 链接: <https://github.com/sb-child/mytm>
- 编程语言: ![rs](https://img.shields.io/badge/-rust-black?logo=Rust)
- 通过 git 安装: `cargo add mytm --git https://github.com/sb-child/mytm`

---

## 简介

一个小型的 Rust 任务管理器库（当前 v0.1.x）。提供"刚好够用"的任务调度/管理抽象，可以直接以 git 依赖的方式引入到项目中使用。MIT 许可证。
